\section{系统测试与结果分析}

\subsection{测试环境与数据集}

系统测试在以下环境进行：

\begin{itemize}
\item 操作系统：Windows 11 Pro
\item 处理器：Intel Core i7-12700H
\item 内存：16GB DDR5
\item 编译器：GCC 13.2.0 (MSYS2)
\item 编译优化：-O2
\end{itemize}

测试关卡选取经典的Microban关卡集，该关卡集按难度分为三个梯队：

\begin{itemize}
\item 简单关卡（Level 1-5）：2-3个箱子，适合验证基本功能
\item 中等关卡（Level 6-10）：3-4个箱子，测试启发式函数效果
\item 困难关卡（Level 11-15）：4-5个箱子，验证死锁检测和优化效果
\end{itemize}

\subsection{解决方案正确性验证}

为保证返回解决方案的正确性，系统实现了解决方案验证器。验证器重放解决方案的每一步，检验：

\begin{itemize}
\item 每步移动是否合法（不能穿墙、不能推动多个箱子）
\item 玩家位置是否连续（玩家的移动距离不能超过1格）
\item 最终状态是否满足目标条件（所有箱子都在目标点上）
\end{itemize}

对全部15个关卡的解决方案验证均通过，正确率100\%。

\subsection{算法效率影响因素分析}

搜索效率受多种因素影响，本节进行敏感性分析。

\textbf{箱子数量}是影响搜索难度的最主要因素。搜索空间随箱子数量呈指数增长：

\begin{equation}
|S| \approx (W \times H)^n
\end{equation}

其中$n$为箱子数量。实验表明，箱子数量每增加1个，平均求解时间增加约10倍。

\textbf{地图复杂度}也是重要因素。狭窄通道和死角落多的地图更容易触发死锁检测，产生更高的剪枝效率。

\textbf{解的深度}影响IDA*的迭代次数。深度每增加一层，IDA*可能需要多迭代一次才能找到解。
