\subsection{数据模型实现}

数据模型均以 \texttt{@dataclass(frozen=True)} 进行装饰，使其不可变且可哈希，从而能够在 GA 进化过程中作为"值类型"安全地在父代与子代之间共享。

\begin{lstlisting}[language=python,caption={核心数据模型 (\texttt{models.py} 节选)}]
@dataclass(frozen=True)
class Course:
    id: str
    name: str
    teacher_id: str
    class_ids: Tuple[str, ...]
    weekly_lessons: int
    required_kind: str    # "lecture" / "lab" / "multimedia" / "any"
    min_capacity: int

@dataclass(frozen=True)
class Lesson:
    """一节课的实例 (Course 按 weekly_lessons 展开后得到)。"""
    lesson_id: int
    course_id: str
    teacher_id: str
    class_ids: Tuple[str, ...]
    required_kind: str
    min_capacity: int

@dataclass
class Schedule:
    """完整排课方案：每个基因 = (slot_idx, room_idx)。"""
    genes: List[Tuple[int, int]]
    instance: ProblemInstance
\end{lstlisting}

\subsection{冲突检测器实现}

冲突检测器采用"按时间槽分桶"的方式工作：先将所有基因按时间槽分组，然后在每个桶内以 $O(b^2)$ 的复杂度检查教师、教室、班级是否在同一时段被重复使用。对于不依赖时间的容量与教室类型两类约束，则对每个基因独立判断。

\begin{lstlisting}[language=python,caption={冲突检测主循环 (\texttt{conflict.py} 节选)}]
def detect(self, schedule: Schedule) -> ConflictReport:
    rep = ConflictReport()
    inst = self.instance

    by_slot = defaultdict(list)
    for i, (slot_i, _room_i) in enumerate(schedule.genes):
        by_slot[slot_i].append(i)

    for slot_i, lesson_ids in by_slot.items():
        seen_teacher, seen_room, seen_class = {}, {}, {}
        for lid in lesson_ids:
            lesson = inst.lessons[lid]
            _, room_i = schedule.genes[lid]
            if lesson.teacher_id in seen_teacher:
                rep.teacher_clashes.append((seen_teacher[lesson.teacher_id], lid))
            else:
                seen_teacher[lesson.teacher_id] = lid
            if room_i in seen_room:
                rep.room_clashes.append((seen_room[room_i], lid))
            else:
                seen_room[room_i] = lid
            for cls in lesson.class_ids:
                if cls in seen_class:
                    rep.class_clashes.append((seen_class[cls], lid))
                else:
                    seen_class[cls] = lid
    # 容量与教室类型检查
    for i, (_slot_i, room_i) in enumerate(schedule.genes):
        lesson, room = inst.lessons[i], inst.room_by_index(room_i)
        if room.capacity < lesson.min_capacity:
            rep.capacity_violations.append(i)
        if lesson.required_kind != "any" and room.kind != lesson.required_kind:
            rep.room_kind_violations.append(i)
    return rep
\end{lstlisting}

\subsection{适应度函数实现}

适应度函数对应论文第四章 4.2 节的公式定义。将硬约束计数乘以高权重 (500\,/\,1000)、将软约束累加值乘以低权重 (1.5\,/\,2\,/\,3\,/\,5)，二者求和即得 cost。

\begin{lstlisting}[language=python,caption={硬代价计算 (\texttt{fitness.py} 节选)}]
def compute_cost(schedule: Schedule, detector: ConflictDetector) -> float:
    rep = detector.detect(schedule)
    hard = (W_TEACHER * len(rep.teacher_clashes)
          + W_ROOM    * len(rep.room_clashes)
          + W_CLASS   * len(rep.class_clashes)
          + W_CAPACITY* len(rep.capacity_violations)
          + W_KIND    * len(rep.room_kind_violations))
    return hard + soft_penalty(schedule)
\end{lstlisting}

\subsection{约束感知的初始化与变异}

实现的关键在于函数 \texttt{feasible\_rooms\_for\_lesson()}，其在 GA 启动时预计算每个课程实例的可行教室集合，后续所有初始化与变异操作均在该集合内进行采样。

\begin{lstlisting}[language=python,caption={可行教室集合预计算 (\texttt{operators.py} 节选)}]
def feasible_rooms_for_lesson(instance: ProblemInstance) -> Dict[int, List[int]]:
    table = {}
    for i, lesson in enumerate(instance.lessons):
        cand = []
        for ri, room in enumerate(instance.classrooms):
            if room.capacity < lesson.min_capacity:
                continue
            if lesson.required_kind != "any" and room.kind != lesson.required_kind:
                continue
            cand.append(ri)
        if not cand:
            cand = list(range(instance.n_rooms))  # 数据无解时退化
        table[i] = cand
    return table

def random_schedule(instance, rng, feasible=None):
    if feasible is None:
        feasible = feasible_rooms_for_lesson(instance)
    genes = [(rng.randrange(instance.n_slots), rng.choice(feasible[i]))
             for i in range(instance.n_lessons)]
    return Schedule(genes=genes, instance=instance)
\end{lstlisting}

\subsection{遗传算法主循环}

GA 主循环约 40 行 Python 代码，在结构上分为初始化、记录历史、精英保留、子代生成与种群替换五个阶段。

\begin{lstlisting}[language=python,caption={GA 主循环 (\texttt{ga.py} 节选)}]
def run(self, progress_cb=None) -> GAResult:
    rng = random.Random(self.config.seed)
    feasible = feasible_rooms_for_lesson(self.instance)
    pop = [random_schedule(self.instance, rng, feasible)
           for _ in range(self.config.population_size)]
    costs = [compute_cost(s, self.detector) for s in pop]
    history = GAHistory()

    for gen in range(self.config.n_generations):
        best_i = min(range(len(pop)), key=lambda i: costs[i])
        history.best_cost.append(costs[best_i])
        history.mean_cost.append(sum(costs)/len(costs))
        history.best_hard.append(
            self.detector.detect(pop[best_i]).total_hard)
        if progress_cb: progress_cb(gen, history, pop[best_i])

        # 精英保留
        elite_idx = sorted(range(len(pop)), key=lambda i: costs[i])[:self.config.elitism]
        new_pop = [pop[i] for i in elite_idx]
        fitnesses = [1.0/(1.0+c) for c in costs]

        while len(new_pop) < self.config.population_size:
            p1 = tournament_select(pop, fitnesses, rng, self.config.tournament_k)
            p2 = tournament_select(pop, fitnesses, rng, self.config.tournament_k)
            if rng.random() < self.config.crossover_prob:
                c1, c2 = uniform_crossover(p1, p2, rng)
            else:
                c1, c2 = p1, p2
            c1 = mutate(c1, rng, self.config.mutation_slot_prob,
                        self.config.mutation_room_prob, feasible)
            c2 = mutate(c2, rng, self.config.mutation_slot_prob,
                        self.config.mutation_room_prob, feasible)
            new_pop.append(c1)
            if len(new_pop) < self.config.population_size:
                new_pop.append(c2)
        pop = new_pop
        costs = [compute_cost(s, self.detector) for s in pop]
    # ... 返回最优个体 ...
\end{lstlisting}

\subsection{自动化截图脚本}

为使论文中的截图能够稳定复现，本项目实现了 \texttt{capture\_screenshots.py} 脚本。该脚本通过 Playwright 驱动一个无头 Chromium 浏览器，按"左侧导航 $\to$ 等待 Streamlit 状态空闲 $\to$ 截图"的流程依次截取所有页面，最终输出至 \texttt{thesis/pic/} 目录。这种"运行系统再截图"的流水线避免了手工截图的不确定性，亦保证了截图与代码版本始终保持一致。
