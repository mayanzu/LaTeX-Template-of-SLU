\section{遗传算法设计与优化}

本章为论文的算法核心部分。首先给出适应度函数的完整定义，进而依次介绍染色体编码、初始化、选择、交叉、变异、精英保留以及算法主循环。本章重点放在公式表述与约束感知机制的设计之上。

\subsection{染色体编码}

对于含有 $n$ 个待排课程实例的问题，本系统采用长度为 $n$ 的整数对序列作为染色体：

\begin{equation}
  C = [g_1, g_2, \ldots, g_n], \qquad g_i = (s_i, r_i)
\end{equation}

其中 $s_i \in \{0, 1, \ldots, |S|-1\}$ 为时间槽下标，$r_i \in \{0, 1, \ldots, |R|-1\}$ 为教室下标。每个基因 $g_i$ 描述第 $i$ 节课程实例 $\ell_i$ 的具体安排。教师 $t(\ell_i)$ 与班级 $G(\ell_i)$ 不参与编码，因其由 $\ell_i$ 自身决定，在搜索过程中保持不变。图~\ref{fig:encoding} 给出了一条长度为 7 的样例染色体的图示。

\begin{figure}[H]
  \centering
  \includegraphics[width=0.95\linewidth]{pic/chromosome_encoding.png}
  \caption{染色体编码示意}
  \label{fig:encoding}
\end{figure}

该编码方式在语义与结构两个层面均具有良好性质：基因与课程实例一一对应使其语义直接，而基因位之间相互独立则便于设计逐位作用的交叉与变异算子。文献中亦讨论过基于优先级的间接编码方式\upcite{8}，本文未予采用，原因在于直接编码在中等规模问题上已具足够的求解能力，且更便于与后续的约束感知机制相结合。

\subsection{适应度函数设计}

为将硬约束与软约束统一纳入同一目标，本系统采用罚函数方式构造代价 (cost)，再通过 fitness $= 1/(1+\text{cost})$ 映射为最大化形式。

\subsubsection{硬约束代价}

设 $C$ 为一个候选解，定义五个硬约束违反计数：

\begin{align}
H_1(C) &= \big|\{(i,j) : i < j,\; s(\ell_i) = s(\ell_j),\; t(\ell_i) = t(\ell_j)\}\big| \quad \text{教师冲突} \\
H_2(C) &= \big|\{(i,j) : i < j,\; s(\ell_i) = s(\ell_j),\; r(\ell_i) = r(\ell_j)\}\big| \quad \text{教室冲突} \\
H_3(C) &= \big|\{(i,j) : i < j,\; s(\ell_i) = s(\ell_j),\; G(\ell_i) \cap G(\ell_j) \neq \emptyset\}\big| \quad \text{班级冲突} \\
H_4(C) &= \big|\{i : \mathrm{cap}(r(\ell_i)) < \mathrm{mincap}(\ell_i)\}\big| \quad \text{容量不足} \\
H_5(C) &= \big|\{i : \mathrm{kind}(\ell_i) \neq \text{any} \wedge \mathrm{kind}(r(\ell_i)) \neq \mathrm{kind}(\ell_i)\}\big| \quad \text{教室类型不符}
\end{align}

对应的硬代价为：

\begin{equation}
  \mathrm{HardCost}(C) = w_1 H_1(C) + w_2 H_2(C) + w_3 H_3(C) + w_4 H_4(C) + w_5 H_5(C)
\end{equation}

其中 $w_1 = w_2 = w_3 = 1000$，$w_4 = w_5 = 500$。资源冲突类违反的权重高于容量与类型违反，原因在于前者会直接导致排课方案不可执行，而后者在某些情形下尚可通过调换教室加以缓解。

\subsubsection{软约束代价}

软约束包含教师偏好、末节安排、班级日课时上限以及班级日内空堂四项。

教师偏好方面，每位教师 $t$ 维护一个偏好时间槽集合 $\mathrm{Pref}(t) \subseteq S$。若 $\mathrm{Pref}(t)$ 非空而某节课被安排在了非偏好时段，则记一次违反：
\begin{equation}
  P_1(C) = \sum_{i=1}^{n} \mathbb{1}[\mathrm{Pref}(t(\ell_i)) \neq \emptyset \wedge s(\ell_i) \notin \mathrm{Pref}(t(\ell_i))]
\end{equation}

末节安排方面，设每天最后一节的下标为 $p_{\max}$，则
\begin{equation}
  P_2(C) = \sum_{i=1}^{n} \mathbb{1}[\mathrm{period}(s(\ell_i)) = p_{\max}]
\end{equation}

班级日课时上限方面，对每个班级 $g$ 和每一天 $d$，设当日课时数为 $N(g,d)$。若 $N(g,d) > 4$ 则按超出量记罚：
\begin{equation}
  P_3(C) = \sum_{g \in G} \sum_{d=0}^{D-1} \max\{0,\; N(g,d) - 4\}
\end{equation}

班级日内空堂方面，设班级 $g$ 在第 $d$ 天的课程节次集合为 $\Pi(g,d) \subseteq \{0,1,\ldots,p_{\max}\}$，则该日空堂数为
\begin{equation}
  \mathrm{gap}(g,d) = \big(\max \Pi(g,d) - \min \Pi(g,d) + 1\big) - |\Pi(g,d)|
\end{equation}
软代价中累加全部正空堂：
\begin{equation}
  P_4(C) = \sum_{g \in G} \sum_{d=0}^{D-1} \mathrm{gap}(g,d)
\end{equation}

四项软代价加权求和：
\begin{equation}
  \mathrm{SoftCost}(C) = \lambda_1 P_1 + \lambda_2 P_2 + \lambda_3 P_3 + \lambda_4 P_4
\end{equation}
其中 $\lambda_1 = 5$，$\lambda_2 = 1.5$，$\lambda_3 = 2$，$\lambda_4 = 3$。上述权重均小于硬代价中最小的 500，从而保证在硬约束尚未完全消除之前，算法不会被软约束误导。

\subsubsection{总代价与适应度映射}

\begin{equation}
  \mathrm{cost}(C) = \mathrm{HardCost}(C) + \mathrm{SoftCost}(C), \qquad
  \mathrm{fitness}(C) = \frac{1}{1 + \mathrm{cost}(C)}
\end{equation}

此 fitness 映射可保证：cost 越小，fitness 越大；且 fitness 始终位于 $(0, 1]$ 区间内，便于锦标赛选择与概率运算。

\subsection{约束感知的初始化}

在排课问题中，存在一类与时间无关的硬约束（即教室容量约束与教室类型约束），其仅由 (课程, 教室) 配对决定。若采用完全随机的初始化，大量初始个体将携带此类违反，浪费早期的进化资源。为此，本文引入预计算的可行教室集合：

\begin{equation}
  \mathcal{R}(\ell_i) = \{r \in R : \mathrm{cap}(r) \geq \mathrm{mincap}(\ell_i) \wedge (\mathrm{kind}(\ell_i) = \text{any} \vee \mathrm{kind}(r) = \mathrm{kind}(\ell_i))\}
\end{equation}

初始化时为每个基因独立采样：
\begin{equation}
  s_i \sim \mathrm{Uniform}\{0, \ldots, |S|-1\}, \qquad r_i \sim \mathrm{Uniform}(\mathcal{R}(\ell_i))
\end{equation}

由此，所有初始个体均自动满足教室容量与类型约束，整个进化过程仅需解决教师、教室、班级三类时间相关的资源冲突。消融实验结果表明 (见第六章 \ref{sec:exp-baseline} 节)，该约束感知机制显著降低了 GA 的收敛代数。约束感知初始化的具体流程如算法~\ref{algo:init} 所示。

\begin{algorithm}[!ht]
\caption{约束感知的随机初始化}\label{algo:init}
\DontPrintSemicolon
\SetAlgoLined
\KwIn{问题实例 $\mathcal{I} = (T, R, S, G, K, L)$；种群规模 $N$}
\KwOut{初始种群 $\mathcal{P}^{(0)} = \{C_1, C_2, \ldots, C_N\}$}

\For{$i \leftarrow 1$ \KwTo $|L|$}{
  $\mathcal{R}(\ell_i) \leftarrow \{r \in R \mid \mathrm{cap}(r) \geq \mathrm{mincap}(\ell_i) \wedge (\mathrm{kind}(\ell_i) = \text{any} \vee \mathrm{kind}(r) = \mathrm{kind}(\ell_i))\}$\;
}
$\mathcal{P}^{(0)} \leftarrow \emptyset$\;
\For{$j \leftarrow 1$ \KwTo $N$}{
  \For{$i \leftarrow 1$ \KwTo $|L|$}{
    $s_i \leftarrow \mathrm{Uniform}\{0, 1, \ldots, |S|-1\}$\;
    $r_i \leftarrow \mathrm{Uniform}(\mathcal{R}(\ell_i))$\;
    $g_i \leftarrow (s_i, r_i)$\;
  }
  $C_j \leftarrow [g_1, g_2, \ldots, g_{|L|}]$\;
  $\mathcal{P}^{(0)} \leftarrow \mathcal{P}^{(0)} \cup \{C_j\}$\;
}
\Return{$\mathcal{P}^{(0)}$}\;
\end{algorithm}

\subsection{选择算子：锦标赛选择}

锦标赛选择每次从种群中随机抽取 $k$ 个个体，取其中适应度最高者作为父代：
\begin{equation}
  \mathrm{Tournament}_k(\mathcal{P}) = \arg\max_{C \in \mathcal{S}} \mathrm{fitness}(C), \quad \mathcal{S} \overset{\text{i.i.d.}}{\sim} \mathcal{P},\; |\mathcal{S}| = k
\end{equation}
本系统默认 $k = 3$。与轮盘赌选择相比，锦标赛选择对适应度的绝对值不敏感，仅依赖相对排名，因而对适应度的尺度变化具有更好的鲁棒性——这一特性在排课这类 cost 可能跨越多个数量级的问题中尤为有用。

\subsection{交叉算子：均匀交叉}

均匀交叉 (Uniform Crossover) 对每个基因位独立做一次伯努利试验，以 $p = 0.5$ 的概率决定是否交换两个父代在该位上的基因：
\begin{equation}
  g_i^{(C_1)} = \begin{cases} g_i^{(P_2)}, & \text{w.p. } 0.5 \\ g_i^{(P_1)}, & \text{otherwise} \end{cases}
\end{equation}
$C_2$ 取互补部分。

值得注意的是，由于父代 $P_1$、$P_2$ 在基因位 $i$ 上的基因均来自 $\mathcal{R}(\ell_i)$，因此经均匀交叉得到的子代仍然满足教室容量与类型约束——交叉算子天然保持了上节所构造的可行性。

\subsection{变异算子：约束感知重采样}

变异分为时间槽变异与教室变异，二者独立进行：
\begin{align}
  s_i' &= \begin{cases} \mathrm{Uniform}\{0,\ldots,|S|-1\}, & \text{w.p. } p_m^{(s)} \\ s_i, & \text{otherwise} \end{cases} \\
  r_i' &= \begin{cases} \mathrm{Uniform}(\mathcal{R}(\ell_i)), & \text{w.p. } p_m^{(r)} \\ r_i, & \text{otherwise} \end{cases}
\end{align}
注意教室变异仅在可行集合 $\mathcal{R}(\ell_i)$ 内采样，从而再次保证变异后的染色体仍然满足教室容量与类型约束。

\subsection{精英保留与替代}

每一代结束时，按 cost 升序对当前种群排序，取前 $E$ 个个体直接进入下一代 (本文取 $E = 2$)。其余位置通过"锦标赛选择 → 概率 $p_c$ 交叉 → 变异"的流水线生成：

\begin{equation}
  \mathcal{P}^{(t+1)} = \{\text{Top-}E(\mathcal{P}^{(t)})\} \cup \{\mathrm{Mutate}(\mathrm{Crossover}(P_1, P_2)) : P_1, P_2 \in \mathcal{P}^{(t)}\}
\end{equation}

精英保留的作用在于防止当前最优解在交叉、变异过程中被无意破坏，本质上是一种隐式的"局部记忆"机制\upcite{15}。

\subsection{终止条件}

本系统采用固定代数终止策略——当迭代达到预设的 $T_{\max}$ 代时停止。虽然亦可使用"连续 $K$ 代最优 cost 不再下降"作为早停条件，但在实测中固定代数更便于参数对比实验，因此默认实现采用前者。

\subsection{算法主流程}

将上述各要素组合，即得完整的遗传算法主流程，如图~\ref{fig:flowchart} 所示，对应的形式化伪代码见算法~\ref{algo:ga}。

\begin{figure}[H]
  \centering
  \includegraphics[width=0.65\linewidth]{pic/ga_flowchart.png}
  \caption{遗传算法主流程}
  \label{fig:flowchart}
\end{figure}

\begin{algorithm}[!ht]
\caption{遗传算法求解排课问题}\label{algo:ga}
\DontPrintSemicolon
\SetAlgoLined
\KwIn{问题实例 $\mathcal{I}$；参数 $(N, T_{\max}, p_c, p_m^{(s)}, p_m^{(r)}, k, E)$}
\KwOut{最优排课方案 $C^\ast$}

$\mathcal{P}^{(0)} \leftarrow \text{ConstraintAwareInit}(\mathcal{I}, N)$\;
\For{$t \leftarrow 0$ \KwTo $T_{\max}-1$}{
  \ForEach{$C \in \mathcal{P}^{(t)}$}{
    $\mathrm{cost}(C) \leftarrow \mathrm{HardCost}(C) + \mathrm{SoftCost}(C)$\;
    $\mathrm{fitness}(C) \leftarrow 1/(1+\mathrm{cost}(C))$\;
  }
  $\mathcal{E} \leftarrow \mathrm{Top}_E(\mathcal{P}^{(t)})$\;
  $\mathcal{P}^{(t+1)} \leftarrow \mathcal{E}$\;
  \While{$|\mathcal{P}^{(t+1)}| < N$}{
    $P_1 \leftarrow \mathrm{Tournament}_k(\mathcal{P}^{(t)})$\;
    $P_2 \leftarrow \mathrm{Tournament}_k(\mathcal{P}^{(t)})$\;
    \eIf{$\mathrm{rand}() < p_c$}{
      $(C_1, C_2) \leftarrow \mathrm{UniformCrossover}(P_1, P_2)$\;
    }{
      $(C_1, C_2) \leftarrow (P_1, P_2)$\;
    }
    $C_1 \leftarrow \mathrm{Mutate}(C_1, p_m^{(s)}, p_m^{(r)})$\;
    $C_2 \leftarrow \mathrm{Mutate}(C_2, p_m^{(s)}, p_m^{(r)})$\;
    $\mathcal{P}^{(t+1)} \leftarrow \mathcal{P}^{(t+1)} \cup \{C_1, C_2\}$\;
  }
}
$C^\ast \leftarrow \arg\min_{C \in \mathcal{P}^{(T_{\max})}} \mathrm{cost}(C)$\;
\Return{$C^\ast$}\;
\end{algorithm}
